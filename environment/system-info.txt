## Nondeterminism notes
- TF32 is enabled by default on Ada GPUs for cuDNN convolutions. The frozen-stem
  feature cache was validated against full forward passes at ~1.2e-3 absolute
  difference, which is the TF32 convolution floor, not a logic error.
- Using the cached frozen-stem features shifts the RNG stream relative to a full
  frame-by-frame run, so cached and uncached runs of the SAME seed are close but
  not bit-identical. Every reported comparison is internally consistent: all arms
  in a table were run under the same caching mode.
- B3_shuffle consumes RNG inside its forward pass to permute frames. Re-scoring a
  B3_shuffle checkpoint under a different RNG stream can move exactly one clip of
  3,783 (0.0264 accuracy points); this is visible in the `single_view_drift`
  column of the seed-level CSV and affects no other arm.
- torch.use_deterministic_algorithms() is NOT set. Runs are seeded and
  reproducible to within the tolerances above, not bitwise across machines.
