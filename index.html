SyncCaps: per-seed results behind every reported number

This page exists so a reviewer can check the manuscript's claims against the raw experiment logs. It contains the per-seed values, the run configuration, the provenance of each figure, and the file manifest — nothing else from the paper.

How to read this

Every accuracy below is certain-tick test accuracy: per-tick logits are prefix-averaged and the model commits at the first tick clearing a fixed certainty threshold, falling back to the final tick. "Hybrid" is the secondary metric reported alongside it. All means are two-seed unless a row is marked otherwise.

checkpoint-backed

Weights retained on disk; the number can be recomputed from the released checkpoint.

log-only

From the hyper-parameter sweep, which archived per-tick and per-class arrays but did not persist weights.

single seed

Only one seed was run. Treat as indicative: the within-arm seed spread on UCF-11 reaches 5.4 points.

Rounding. The manuscript computes gaps from rounded means (86.6 − 76.2 = +10.4 on UCF101). From unrounded means the same gap is +10.33. Both are shown below so the arithmetic is checkable either way.

Does the learned decay do the work?

backs §7

The readout's per-pair decay ρ is the only component that can encode temporal order. Freezing ρ at 0 turns the statistic into an order-agnostic Gram entry. This control was extended from one seed to two after the first draft, and the second seed reversed the reading.

Learned decay vs. frozen ρ = 0, UCF-11, 4-conv stem
Arm seed 42seed 1337 meanspreadhybrid mean
B1_sync (learned ρ)87.5587.9787.760.4186.10
B2_gram (ρ frozen at 0)83.8289.2186.515.3986.10
Difference+3.73−1.24+1.24—0.00

Why this matters for the claim. The frozen-decay arm's better seed (89.21) exceeds both seeds of the learned-decay arm; the two arms are identical on the hybrid metric to two decimal places; and the spread within the frozen arm (5.39) is more than four times the gap between the arms (1.24). Temporal decay is therefore not resolvable as a source of accuracy here. The manuscript attributes the gain to the second-order co-activation representation rather than to temporal order.

Consistent with this, the trained decay values sit near the ρ = 0 limit: across the 1024 UCF-11 pairs the learned memory e−ρ spans [0.904, 1.000] with median 0.998 (docs/paper/figures/tick_strategy_ucf11.json).

Provenance caveats

Stated plainly, because these are the places where two numbers for the same model legitimately differ.

  • The UCF-11 B1 headline is log-only. The 87.55 / 87.97 pair comes from the sweep, which archived per-tick and per-class arrays but did not persist weights. The released seed-42 checkpoint reproduces 85.48 certain-tick at mean exit tick 6.50, against the sweep's 87.55 at 6.73. Recomputing both arms from saved checkpoints leaves the same-stem gap at about +12.4.
  • Two different scalar baselines exist on UCF-11. 87.76 is the headline sweep; 88.59 is the re-run inside the pose-ablation batch. Figures and tables state which one they use.
  • Two different "routing" numbers exist. 86.3 is the TR-Caps routing model; 79.25 is the A1 sync-readout-over-routing arm trained in the SyncCaps batch.
  • The UCF101-full seed-1337 run was resumed after a hardware interruption and reproduces the expected scale.
  • B2_gram seed 1337 was added after the first draft. It uses the same protocol as seed 42 (LR 1e-3, 12 epochs) and is checkpoint-backed.

Datasets

Both benchmarks are public and were used as distributed — no re-collection, no private splits. The stratified S3 partition is derived deterministically from the run seed, so it is reproducible from the seed alone.

Reproducing these numbers

Two levels, costing very different amounts.

Recompute the statistics

Seconds, no GPU, no dataset. python verify.py in the repository recomputes every published mean, gap and cost figure from the archived per-seed logs and fails loudly on any mismatch. Standard library only.

Retrain an arm

Needs the public datasets above, PyTorch and one GPU — roughly an hour per arm at the configuration below. The readout is selected by a single argument, so the same-stem control is one flag away from the headline model.

The same-stem control was built to be re-run cheaply: B0 and B1 are the same network up to the readout module, chosen by readout='sync' versus readout='linear'. Every other setting in the configuration table below is held fixed between them.
